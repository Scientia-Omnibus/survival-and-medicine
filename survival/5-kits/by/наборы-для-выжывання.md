# Раздзел 5: Наборы

> Нават самы маленькі набор для выжывання, калі ён правільна сабраны, неацэнны пры сутыкненні з праблемай выжывання. Калі ўзнікне сітуацыя, вы можа быць не зможаце проста купіць тое, што трэба, — таму добра мець некаторыя неабходныя рэчы на гэтыя выпадкі.

### НАБОРЫ ДЛЯ ВЫЖЫВАННЯ

Навакольнае асяроддзе — ключ да тыпаў прадметаў, якія спатрэбяцца ў вашым наборы для выжывання. Колькасць рыштунку ў наборы залежыць ад таго, як вы яго будзеце насіць. Набор, які носіцца на целе, павінен быць меншым за той, што перавозіцца ў транспартным сродку. Трымайце самыя важныя прадметы на целе. Напрыклад, карта і компас заўсёды павінны быць на целе, як і запальнічка ды мультытул.

Складаючы свой набор для выжывання, выбірайце прадметы шматабсяжныя, кампактныя, лёгкія, трывалыя і, што найважней, функцыянальныя. Прадмет не добры, калі ён выглядае выдатна, але не робіць таго, для чаго прызначаны. Прадметы павінны дапаўняць адзін аднаго ад пласта да пласта. Сігнальнае люстэрка ў кішэні можа падмацоўвацца ракеткамі-алоўкамі і сігнальнай панэллю ў заплечніку.

Ваш набор для выжывання не абавязаны быць мудрагелістым. Вам патрэбныя толькі функцыянальныя прадметы, што задаволяць вашыя патрэбы, і футляр для іх захоўвання. Кантэйнер павінен быць:

- Водаадпорным або воданепранікальным
- Лёгкім для нашэння або мацавання да цела
- Прыдатным для розных па памеры кампанентаў
- Трывалым

Ваш набор для выжывання павінен быць падзелены на катэгорыі, кожная з якіх змяшчае прадметы, што дазволяць падтрымліваць вашыя базавыя патрэбы.
