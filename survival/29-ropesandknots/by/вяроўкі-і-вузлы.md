## Тэрміналогія

| Тэрмін | Азначэнне |
|---|---|
| Пятля | Просты згіб вяроўкі, дзе вяроўка не перасякае саму сябе |
| Апраўка вузла | Правільнае выраўноўванне ўсіх частак вузла. Няздольнасць зрабіць гэта можа знізіць моц на 50%. |
| Фрапы | Зацягванне абвязкаў шляхам абвівання вяроўкі перпендыкулярна вакол віткоў, што трымаюць жэрдкі разам |
| Абвязкі | Звязванне дзвюх або трох жэрдак разам з дапамогай віткоў і фрапаў; пачынаюцца і заканчваюцца простымі выбленкамі |
| Напрамак скруткі | Кірунак скручвання вяроўкі |
| Пятля (loop) | Утвараецца перасячэннем бегучага канца праз або пад стаячым канцом, ствараючы кольца |
| Пятачок | Рэшткавы бегучы канец пасля завязвання вузла; трымайце менш за 10 см (4 цалі) |
| Бегучы канец | Свабодны або працоўны канец вяроўкі, які выкарыстоўваецца для завязвання вузла |
| Стаячы канец | Нерухомая частка вяроўкі |
| Віток | Пятля вакол прадмета, дзе бегучы канец працягваецца ў кірунку, супрацьлеглым да стаячага канца |
| Абмотванне | Шчыльнае абвіванне канца вяроўкі дробным шнуром або стужкай, каб прадухіліць раскручванне |
| Віткі | Простыя абвіванні вяроўкі вакол жэрдак; пачынаюцца і заканчваюцца простымі выбленкамі |

## Базавыя вузлы

| Вузел | Выкарыстанне | Характарыстыкі |
|---|---|---|
| Простая выбленка | Простае замацаванне | Мае тэндэнцыю развязвацца без нагрузкі. Замяніце канцавым вузлом. |
| Канцавы вузел | Агульны стотар-вузел; часовае абмотванне | Зніжае моц вяроўкі на 55%. Замяняе простую выбленку як канцавы вузел. |
| Прамы вузел | Завязванне дзвюх вяровак роўнага дыяметра | Два адваротныя канцавыя вузлы (правы над левым, левы над правым). Замацуйце канцавым вузлом на абодвух канцах. Лёгка правяраць. |
| Паўтара абароту і дзве простыя выбленкі | Якарны вузел для высокіх нагрузак; вяроўка да жэрдкі або дрэва | Не заклініваецца пад нагрузкай. Асноўны якарны вузел для аднавяровачных мастоў. |
| Простая выбленка з абвіваннем | Мацаванне вяроўкі да дрэва або трубы | Лёгкі якарны вузел. Нацяжэнне мусіць захоўвацца, інакш ён слізгае. Дадайце дадатковую пятлю для прадухілення слізгання. |
| Авечы штык | Укарочванне вяроўкі; абыход слабага мясца | Часовы, калі кольцы не замацаваныя да стаячай часткі на абодвух канцах. |
| Падвойны шкег | Злучэнне дзвюх вяровак роўнага або няроўнага дыяметра; мокрая вяроўка | Не будзе слізгаць або зацягвацца пад нагрузкай. Можа злучыць некалькі вяровак у адну. |
| Прусік | Завязванне кароткай вяроўкі вакол даўжэйшай для ўздыму | Слізгае, калі вольны, трымае пад нацяжэннем. Можна завязаць канцом або пятлёй вяроўкі. |
| Булинь | Стварэнне фіксаванай пятлі, якая не слізгае і не зацягваецца пад нацяжэннем | Быў стандартным ратавальным вузлом. Пятля размяшчаецца вакол цела. |
| Вузёл «восьмёрка» | Асноўны ратавальны і якарны вузел | Мацнейшы за булинь. Лягчэй вязаць і правяраць. Цяжэй развязаць, калі мокры. Прадухіляе праслізванне канца праз мацаванні. |

## Абвязкі

| Тып | Выкарыстанне |
|---|---|
| Абвязка нажніцамі | Завязванне дзвюх жэрдак пад вуглом, каб утварыць нажніцы |
| Квадратная абвязка | Завязванне дзвюх жэрдак пад прамым вуглом |
| Трохножная абвязка | Завязванне трох жэрдак разам для будаўніцтва троножкі |

> Зацягвайце ўсе вузлы перад тым, як падвяргаць іх нагрузцы. Слаба завязаны вузел можа дэфармавацца пад нацяжэннем і слізгаць або развязацца.
